# regression-lab

A hands-on collection of machine learning and data science projects, built while learning to translate real-world datasets into predictive models.

## Repository Contents

* **[01-car-price-prediction](01-car-price-prediction)**: Automotive price prediction using regression techniques.
* **[Breast Cancer Wisconsin Diagnosis](Breast%20Cancer%20Wisconsin%20(Diagnostic)%20project%20use%20logistic%20regression)**: Binary classification using Logistic Regression.
* **[Credit Card Fraud Detection](credit-card-fraud-detection.ipynb)**: Imbalanced classification using Decision Trees and Support Vector Machines.
* **[Titanic Dataset Preprocessing](titanic-dataset-preprocessing)**: End-to-end data preprocessing pipeline covering missing value imputation, IQR outlier capping, categorical encoding, feature scaling (Min-Max and Standardization), and SMOTE class balancing.
