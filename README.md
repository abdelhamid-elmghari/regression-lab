# regression-lab

A hands-on collection of machine learning and data science projects, built while learning to translate real-world datasets into predictive models.

## Repository Contents

* **[01-car-price-prediction](01-car-price-prediction)**: Automotive price prediction using regression techniques.
* **[Breast Cancer Wisconsin Diagnosis](Breast%20Cancer%20Wisconsin%20(Diagnostic)%20project%20use%20logistic%20regression)**: Binary classification using Logistic Regression.
* **[Credit Card Fraud Detection](credit-card-fraud-detection.ipynb)**: Imbalanced classification using Decision Trees and Support Vector Machines.

### Practical Data Preprocessing Projects

* **[Titanic Dataset Preprocessing](practical%20projects/titanic-dataset-preprocessing)**: End-to-end data preprocessing pipeline covering missing value imputation, IQR outlier capping, categorical encoding, feature scaling (Min-Max and Standardization), and SMOTE class balancing.
* **[Transactions Dataset Preprocessing](practical%20projects/transactions-dataset-preprocessing)**: Comprehensive bank transaction data preprocessing & fraud detection pipeline covering duplicate removal, IQR outlier analysis, leak-free preprocessing (ColumnTransformer), RobustScaler vs. StandardScaler comparison, class balancing (OverSampling/SMOTE-NC), and production joblib export.
